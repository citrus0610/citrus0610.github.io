ReDragonica - Accurate ATK Formula on OL

Set comparison for normal F8

full bdl vs. full leo + black fedora






bdl set effect for OL
leo set effect
black fedora and brindle set effect

stat difference from leo to bdl

  • cd: 105 - 30 = 75
    (bdl 105, leo 30)
  • fcr: 4.8 - 3 = 1.8
    (bdl 4.8, leo 3)
  • spell dmg: -20
    (leo 10, black fedora 10)
  • awaken dmg: -20
    (black fedora 20)
  • boss dmg: 10
    (bdl 10)

assume cd 725 means the cd multiplier is 725/100 = 7.25

  • base expected dmg
    = atk * critical multiplier
    = atk * [(1 - fcr) + fcr * (cd/100)]

the 2+2 is blast fate for comparision
we only compare sets for highest dmg so we don’t consider 2+2 blast swif

set 1: leo 2+2

  • atk 83086
    [1692 * 1.1 + 15829 + 13342 * 1.244 + (32760 - 32106) + 565] * 2.34
    = 83085.5
  • fcr 68.7
  • cd 711
  • boss 31.3
  • spell 37
  • awaken 20
  • base expected dmg
    = 83086 * [(1 - 0.687) + 0.687 * 7.11]
    = 431845.3

set 2: bdl 2+2
(fcr +1.8, cd +75, boss +10, str +120, spell -20, awaken -20 compared to set 1)

  • atk
    = [(1692 + 120 * 2) * 1.1 + 15829 + 13342 * 1.244 + (32760 - 32106) + 565] * 2.34
    = 83703.3
  • fcr 68.7 + 1.8 = 70.5
  • cd 711 + 75 = 786
  • boss 31.3 + 10 = 41.3
  • spell 37 - 20 = 17
  • awaken 20 - 20 = 0
  • base expected dmg
    = 83703 * [(1 - 0.705) + 0.705 * 7.86]
    = 488515.8

set 3: leo vital
(fcr -2, cd -50, final dmg amplification +15%, str +100 compared to set 1)

  • atk
    = [(1692 + 100 * 2) * 1.1 + 15829 + 13342 * 1.244 + (32760 - 32106) + 565] * (2.34 + 0.15)
    = 88959.3
  • fcr 68.7 - 2 = 66.7
  • cd 711 - 50 = 661
  • boss 31.3
  • spell 37
  • awaken 20
  • base expected dmg
    = 88959 * [(1 - 0.667) + 0.667 * 6.61]
    = 421832

set 4: bdl vital
(fcr -2, cd -50, final dmg amplification +15%, str +100 compared to set 2)

  • atk
    = [(1692 + 120 * 2 + 100 * 2) * 1.1 + 15829 + 13342 * 1.244 + (32760 - 32106) + 565] * (2.34 + 0.15)
    = 89616.7
  • fcr 70.5 - 2 = 68.5
  • cd 786 - 50 = 736
  • boss 41.3
  • spell 17
  • awaken 0
  • base expected dmg
    = 89616 * [(1 - 0.685) + 0.685 * 7.36]
    = 480037

set 5: leo swif
(fcr -2, cd -50, final dmg amplification +20% compared to set 1)

  • atk
    = [1692 * 1.1 + 15829 + 13342 * 1.244 + (32760 - 32106) + 565] * (2.34 + 0.2)
    = 90186.8
  • fcr 68.7 - 2 = 66.7
  • cd 711 - 50 = 661
  • boss 31.3
  • spell 37
  • awaken 20
  • base expected dmg
    = 90186 * [(1 - 0.667) + 0.667 * 6.61]
    = 427650.2
  • dmg of non-awaken skill on mob
    = base expected dmg * spell dmg
  • dmg of awaken skill on mob
    = base expected dmg * spell dmg * awaken dmg
  • dmg of non-awaken skill on boss
    = base expected dmg * spell dmg * boss dmg
  • dmg of awaken skill on boss
    = base expected dmg * spell dmg * awaken dmg * boss dmg

we should also times back dmg on every dmg
but we we assume the chaotic parts are the same and the back dmg is the same
we only want to know which number is greater
so we don’t need to multiply them by back dmg
the result will still be the same no matter whether every dmg is multiplied by same back dmg

for example, if we want to compare the 2 values
1.2 * 1.7 * 1.6 and 1.4 * 1.5 * 1.6
they are both multiplied by 1.6
so we only need to calculate and compare 1.2 * 1.7 and 1.4 * 1.5
we don’t need to multiply them by 1.6
