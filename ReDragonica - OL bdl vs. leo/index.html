bdl set effect for OL
leo set effect
black fedora and brindle set effect

Stat difference from full leo + black fedora to full bdl

  • CD: $105-30=75$
    (bdl 105, leo 30)
  • FCR: $4.8-3=1.8$
    (bdl 4.8, leo 3)
  • patk: $(120+80) \times 5 = 1000$
    (bdl 120 str, bdl head 80 str, 1str = 5patk for OL)
  • spell dmg: $-(10+10)=-20$
    (leo 10, black fedora 10)
  • awaken spell dmg: $-20$
    (black fedora 20)
  • boss dmg: $10$
    (bdl 10)

Assume CD 725 means the CD multiplier is 725/100 = 7.25

Without vowbuff
