stat difference from leo to bdl

  • cd: 120 - 30 = 90
    (bdl 120, leo 30)
  • fcr: 5.5 - 3 = 2.5
    (bdl 5.5, leo 3)
  • spell dmg: -20
    (leo 10, black fedora 10)
  • awaken dmg: -20
    (black fedora 20)
  • boss dmg: 10
    (bdl 10)

assume cd 725 means the cd multiplier is 725/100 = 7.25

  • base expected dmg
    = atk * critical multiplier
    = atk * [(1 - fcr) + fcr * (cd/100)]

for 4 fate, we need to use this formula to calculate expected critical multiplier
$(fcr\cdot cd/100) + 2.5(1-fcr) - 1.5(1-fcr)^6$
for more details about the formula, please check the article
ReDragonica - Math Proof of the Expected Dmg Multiplier for 4 Fate

set 1: leo fate

  • atk 32323
    [6465 * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * 1.25
    = 32324.7
  • fcr 56
  • cd 714
  • boss 32
  • spell 35
  • awaken 80
  • base expected dmg
    = 32323 * [0.56 * 714 / 100 + 2.5 * (1 - 0.56) - 1.5 * (1 - 0.56)^6]
    = 164443.7

set 2: bdl fate
(fcr +2.5, cd +90, boss +10, str +110, spell -20, awaken -20 compared to set 1)

  • atk
    = [(6465 + 110 * 5) * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * 1.25
    = 33081
  • fcr 56 + 2.5 = 58.5
  • cd 714 + 90 = 804
  • boss 32 + 10 = 42
  • spell 35 - 20 = 15
  • awaken 80 - 20 = 60
  • base expected dmg
    = 33081 * [0.585 * 804 / 100 + 2.5 * (1 - 0.585) - 1.5 * (1 - 0.585)^6]
    = 189661.2

set 3: leo vital
(cd -50, final dmg amplification +15%, str +100 compared to set 1)

  • atk
    = [(6465 + 100 * 5) * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * (1.25 + 0.15)
    = 36973.7
  • fcr 56
  • cd 714 - 50 = 664
  • boss 32
  • spell 35
  • awaken 80
  • base expected dmg
    = 36973 * [(1 - 0.56) + 0.56 * 6.64]
    = 153748.5

set 4: bdl vital
(cd -50, final dmg amplification +15%, str +100 compared to set 2)

  • atk
    = [(6465 + 110 * 5 + 100 * 5) * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * (1.25 + 0.15)
    = 37820.7
  • fcr 58.5
  • cd 804 - 50 = 754
  • boss 42
  • spell 15
  • awaken 60
  • base expected dmg
    = 37820 * [(1 - 0.585) + 0.585 * 7.54]
    = 182515.5

set 5: leo 2+2
(fcr +2 compared to set 1)

  • atk 32323
  • fcr 56 + 2 = 58
  • cd 714
  • boss 32
  • spell 35
  • awaken 80
  • base expected dmg
    = 32323 * [(1 - 0.58) + 0.58 * 7.14]
    = 147431.6

set 6: bdl 2+2
(fcr +2 compared to set 2)

  • atk 33081
  • fcr 58.5 + 2 = 60.5
  • cd 804
  • boss 42
  • spell 15
  • awaken 60
  • base expected dmg
    = 33081 * [(1 - 0.605) + 0.605 * 8.04]
    = 173979.5

set 7: leo swif
(cd -50, final dmg amplification +20% compared to set 1)

  • atk
    = [6465 * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * (1.25 + 0.2)
    = 37496.7
  • fcr 56
  • cd 714 - 50 = 664
  • boss 32
  • spell 35
  • awaken 80
  • base expected dmg
    = 37496 * [(1 - 0.56) + 0.56 * 6.64]
    = 155923.3

swif needs leo’s move speed buff to reach 450, so can’t use bdl

  • dmg of non-awaken skill on mob
    = base expected dmg * spell dmg * regular monster dmg
  • dmg of awaken skill on mob
    = base expected dmg * spell dmg * awaken dmg * regular monster dmg
  • dmg of non-awaken skill on boss
    = base expected dmg * spell dmg * boss dmg
  • dmg of awaken skill on boss
    = base expected dmg * spell dmg * awaken dmg * boss dmg

we should also times back dmg on every dmg
but we we assume the chaotic parts are the same and the back dmg is the same
we only want to know which number is greater
so we don’t need to multiply them by back dmg
the result will still be the same no matter whether every dmg is multiplied by same back dmg

for example, if we want to compare the 2 values
1.2 * 1.7 * 1.6 and 1.4 * 1.5 * 1.6
they are both multiplied by 1.6
so we only need to calculate and compare 1.2 * 1.7 and 1.4 * 1.5
we don’t need to multiply them by 1.6
