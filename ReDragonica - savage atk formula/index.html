ReDragonica - Accurate ATK Formula on Savage

ATK formula






  • total str = 1301
  • char = total str * 5
    = 1301 * 5 = 6505
  • item = 18227
  • final dmg amplification % = 25%
  • final dmg amplification value
    = (char + item) * final dmg amplification %
    = (6505 + 18227) * 0.25
    = 6183
  • basic atk bonus % = 10%
  • passive atk = 520
  • weapon base max atk = 6315
  • weapon enchant max atk = 7533
  • weapon total max atk = 15236
  • weapon max physical atk % = 10% + 12% = 22%
    (need to include chaotic part)
  • final atk
    = [char * basic atk bonus + weapon enchant max atk + weapon base max atk * weapon max physical atk % + (item - weapon total max atk) + passive atk] * final dmg amplification %
    = [6505 * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * 1.25
    = 32379.7

Char

value of char is only affected by total str, which is total str * 5

my leo shoe has str 38 + 15 = 53


after we take off the leo shoe
(str -53)


  • total str = 1301 - 53 = 1248
  • char = total str * 5
    = 1248 * 5 = 6240
  • final atk
    = [6240 * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * 1.25
    = 32015.3

Basic atk bonus

savage’s original basic atk bonus is 5%
home buff has atk power buff 5%, which adds on the basic atk bonus
So the basic atk bonus is 5% + 5% = 10%


after we delete the atk power buff 5%


the basic atk bonus becomes 5%

  • final atk
    = [6505 * 1.05 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * 1.25
    = 31973.1

Passive skills

passive atk is from this 2 passive skills, which is 200 + 320 = 520
if the claw mastery is only lv5, it only +125 atk and the passive atk becomes 125 + 320 = 445



Final dmg amplification %

set effect of bonus physical atk dmg on F8 accesories directly adds the percentage on final dmg amplification %

vital 15%

swif 20%

gambit 100%

titan 5%

bangle: 10%

my bangle has str 8 and bonus physical atk dmg 10%


after we take off the bangle
(str -8, final dmg amplification -10%)


  • total str = 1301 - 8 = 1293
  • char = total str * 5
    = 1293 * 5 = 6465
  • final dmg amplification % = 25% - 10% = 15%
  • final dmg amplification value
    = (char + item) * final dmg amplification %
    = (6465 + 18227) * 0.15
    = 3703.8
  • final atk
    = [6465 * 1.1 + 7533 + 6315 * 1.22 + (18227 - 15236) + 520] * 1.15
    = 29738.7

Item

  • item = weapon total max atk + fixed atk



the total atk on my weapon is 13606 to 15236, so the weapon total max atk is 15236
the enchant atk on my weapon is 6787 to 7533, so the weapon enchant max atk is 7533

the components of the weapon total max atk

  • default atk = weapon base max atk = 6315
  • enchant atk = weapon enchant max atk = 7533
  • the 1st soulcraft atk
    = weapon base max atk * soulcraft max atk %
    = 6315 * 12%
    = 6315 * 0.12
    = 757.8
    should not include the chaotic part
    the chaotic part does not add on it and is not displayed on item
  • monster card atk
    = weapon base max atk * card max atk %
    = 6315 * 10%
    = 6315 * 0.1
    = 631.5

which is 6315 + 7533 + 757 + 631 = 15236

Fixed atk

  • fixed atk
    = item - max atk on weapon
    = 18227 - 15236
    = 2991

it comes from:

  • max patk on gears
    F8 accesories, special options on bdl and low level gears
  • gears that add atk directly
    IM weapon atk, easter balloon, noble pin, low level gears

Conclusion

with this accurate atk formula, we can predict final atk when we change stats
or when we change to other f8 sets but keep all other stats the same

(str +100, final amplification +15%)

  • char = total str * 5
    = 1401 * 5 = 7005
