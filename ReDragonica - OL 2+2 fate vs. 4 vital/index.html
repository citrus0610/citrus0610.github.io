ReDragonica - OL 2+2 fate vs. 4 vital

Vital 15% calculation

vital 15% adds the percentage on final damage amplification
which means it directly adds on 134% to be 149%
(1654+32760)*1.34 = 46114 matches the approximate increased value shown in the image


if change to vital and the stats keep the same
patk will increase (1654+32760)*0.15+500 = 5662
(vital 2 set effect +100 str and 1str = 5patk for OL)
patk will become 82988+5662 = 88650

2+2 fate vs. 4 vital

2+2 fate

  • CD 694
  • FCR 68.8%
  • patk 82988

4 vital (CD -50, FCR -2, patk +5662)

  • CD 644
  • FCR 66.8%
  • patk 88650

Assume CD 725 means the CD multiplier is 725/100 = 7.25
expectation value of dmg multiplier
$= \text{patk multiplier} \times ((1 - FCR) + FCR \times CD/100)$
patk multiplier on vital is 88650/82988 = 1.068

Set Expectation value of dmg multiplier
2+2 fate $(1 - 0.688) + 0.688 \times 6.94 = 5.087$
4 vital $1.068 \times ((1 - 0.668) + 0.668 \times 6.44) = 4.949$

5.087/4.949 = 1.027
Therefore, expected dmg of 2+2 fate is 2.7% higher than 4 vital
