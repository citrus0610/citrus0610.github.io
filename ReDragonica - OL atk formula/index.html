ReDragonica - Accurate ATK Formula on Overlord

the formula is almost the same as savage’s
only the constants are different
we only listed the difference for OL in this article
for more details about the formula, please refer to the article
ReDragonica - Accurate ATK Formula on Savage

ATK formula






  • char total = 1692
  • item total = 32760
  • final dmg amplification % = 134%
  • final dmg amplification value
    = (char total + item total) * final dmg amplification %
    = (1692 + 32760) * 1.34
    = 46165.6
  • basic atk bonus % = 10%
  • passive atk = 565
  • weapon base max atk = 13342
  • weapon enchant max atk = 15829
  • weapon total max atk = 32106
  • weapon max physical atk %
    = 10% + 10% * 1.2
    = 10% + 14.4%
    = 24.4%
    (need to include chaotic part)
  • final atk
    = [char total * basic atk bonus + weapon enchant max atk + weapon base max atk * weapon max physical atk % + (item total - weapon total max atk) + passive atk] * final dmg amplification %
    = [1692 * 1.1 + 15829 + 13342 * 1.244 + (32760 - 32106) + 565] * 2.34
    = 83085.5

Char total

str affects the char total
if increase/decrease 100 str, the char total will increase/decrease 100 * 2

for example, if change my str from 606 to 726
it adds 726 - 606 = 120 str
the char total will add 120 * 2 = 240
and become 1692 + 240 = 1932

Basic atk bonus

OL’s original basic atk bonus is also 5%
home buff adds 5%
so the basic atk bonus is also 5% + 5% = 10%
max atk % on a medal also adds on basic atk bonus instead of weapon max physical atk %

Passive atk

it’s from this 2 passive skills, which is 145 + 420 = 565



Final dmg amplification %

advanced sword mastery adds 11%


warrior’s bonds adds 5%


grizzly power adds 11%


wild rage adds 22%


bloody roar adds 50%
when OL’s HP is lower than 25%, it adds 25% more


bangle adds 10%

so the final dmg amplification is
11% + 5% + 11% + 22% + 50% + 25% + 10% = 134%

Usage

For example, if change my 2+2 blast fate to 4 vital
(str +100, final amplification +15%)
and keep others stats the same

the final atk will become
[(1692 + 100 * 2) * 1.1 + 15829 + 13342 * 1.244 + (32760 - 32106) + 565] * (2.34 + 0.15)
= 88959.3
