ReDragonica - ninja bdl vs. 2+2+2

Full bdl vs. 2+2+2 (2 leo + black fedora + 1 brindle + 2 bdl)



leo set effect
black fedora and brindle set effect
bdl set effect for ninja

Stat difference from 2+2+2 to full bdl

  • CD: $120-30=90$
    (bdl 120, leo 30)
  • FCR: $5.5-3=2.5$
    (bdl 5.5, leo 3)
  • patk: $120 \times 8 = 960$
    (bdl 120 str, 1str = 8patk for ninja)
  • spell dmg: $-(10+10+10)=-30$
    (leo 10, black fedora 10, brindle set 10)
  • awaken spell dmg: $-20$
    (black fedora 20)
  • boss dmg: $10$
    (bdl 10)

Assume CD 725 means the CD multiplier is 725/100 = 7.25
and we don’t consider 110 agi

Without vowbuff

Stat Full bdl Full leo + black fedora Multiplier
patk $30700+960=31660$ 30700 $30700/31660=0.970$
CD $698+90=788$ 698 $698/788=0.886$
FCR $58.2+2.5=60.7$ 58.2
spell dmg $45-30=15$ 45 $1.45/1.15=1.261$
awaken spell dmg $80-20=60%$ 80 $1.80/1.60=1.125$
boss dmg $37.5+10%=47.5%$ 37.5 $1.375/1.475=0.932$

expected value of multiplier on non-crit and crit
$= (1 - FCR) + FCR \times CD/100$

  • full bdl: $(1 - 0.607) + 0.607 \times 7.88 = 5.176$
  • 2+2+2: $(1 - 0.582) + 0.582 \times 6.98 = 4.480$

$4.48/5.176=0.866$

without vowbuff, only the expected dmg of non-awaken skill on boss decreases a bit
with vowbuff, only the crit dmg and expected dmg of non-awaken skill on boss decrease a bit
all other dmgs increased
Therefore, 2+2+2 is better than full bdl
